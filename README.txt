DINI FOOD HOUSE WEBSITE

1. Extract this ZIP file.
2. Open index.html in a browser to preview the website.
3. Your supplied logo is included as assets/dini-food-house-logo.png.

BEFORE PUBLISHING:
- Menu ordering and the special offer are connected to +94 77 557 2256. Change RESTAURANT.whatsappNumber in script.js if the restaurant number changes; use digits only with country code.
- The menu includes seven categories and the requested items. Prices are configured in the menuPrices object in script.js and displayed in LKR.
- The Seafood Rice Pack special offer is priced at Rs. 2,500 and includes one free Watalappan.
- Menu items use the supplied photos in their matching category folders under assets. Bibikkan and Kavum use the clean placeholder image until their photos are added; unavailable menu photos also fall back to the placeholder.
- To change a menu photo, copy it into assets/menu, then replace that dish's path in the menuImages object in script.js. For example: "Chicken Rice and curry": "assets/menu/chicken-rice.jpg". Each dish has its own editable entry.
- The special offer uses a supplied rice photo and the Watalappan placeholder in assets/menu; replace either image path in index.html to use your own photo.
- Restaurant contact details are prefilled. Update the RESTAURANT object in script.js if they change.

Google Fonts and existing gallery photos load from the internet. Website images open in an in-page lightbox; the menu, special offer, floating order link, and contact form use WhatsApp to prepare orders/messages.
This is a front-end website. It does not include an admin dashboard, database, online payment gateway, or order storage.
